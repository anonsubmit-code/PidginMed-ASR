#PidginMed-ASR
PidginMed-ASR is a Nigerian Pidgin English medical speech benchmark for Automatic Speech Recognition (ASR) evaluation in low-resource clinical settings.

This repository accompanies the NeurIPS 2026 submission:

PidginMed-ASR: A Nigerian Pidgin English Medical Speech Benchmark for Automatic Speech Recognition

The benchmark contains 5,470 Nigerian Pidgin medical utterances paired with aligned speech recordings and transcriptions collected from native speakers.
